## Features

- **Images** — paste with `Ctrl+V` (screenshots, browser images, copied files) or drag & drop files. Resize from the corner handle or with the mouse wheel.
- **Notes** — double-click empty space. Bold, italic, underline, strikethrough, text color, highlight, per-selection font size, fonts, bullets and **checklists**.
- **Links** — paste or drop a web address on the board to get a link card with the page title (double-click opens it). In notes, addresses become links as you type, and `Ctrl+K` links the selected text.
- **Text-only notes** — no paper, just text with a soft outline that stays readable on any wallpaper.
- **Pen** — draw and highlight over anything, with undo.
- **Lives on your desktop** — background opacity slider (fully transparent works), always on top / normal / behind other windows, lock position & size, maximize, fit window to content.
- **Light** — a ~0.6 MB executable, 0% CPU while idle, everything auto-saved.
- **Languages** — English, 한국어, 日本語, 简体中文, 繁體中文 (follows Windows; change it from the right-click menu).

## Download

Grab the latest build from **[Releases](https://github.com/Eastar0102/StickerBoard/releases/latest)** (Windows 10/11, x64):

| File | Size | Notes |
| --- | --- | --- |
| `StickerBoard-<version>-win-x64.exe` | ~0.6 MB | Needs the [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) |
| `StickerBoard-<version>-win-x64-standalone.exe` | larger | Runs as is, nothing to install |

No installer — just run the exe. The builds are not code-signed, so Windows SmartScreen may warn on first launch (**More info → Run anyway**).

## Usage

| Action | How |
| --- | --- |
| Paste image / text | `Ctrl+V` (text becomes a note, a web address becomes a link card) |
| New note | Double-click empty space, or the **+** button |
| Move | Drag an image, or a note's top strip |
| Resize | Corner handle (`Shift` = free aspect ratio) or mouse wheel over an image |
| Delete / undo delete | `Del` / `Ctrl+Z` |
| Note formatting | `Ctrl+B` `Ctrl+I` `Ctrl+U`, strikethrough `Ctrl+Shift+X`, bullets `Ctrl+Shift+L` |
| Checklist | `Ctrl+Enter` adds a box or toggles it; clicking ☐ checks it |
| Note text size | `Ctrl+Wheel` |
| Links in notes | Typed addresses link automatically; `Ctrl+K` links the selection; `Ctrl+click` opens |
| Pen | `P` (`H` highlighter, `E` eraser, `Ctrl+Z` undo, `Esc` done) |
| Maximize | `F11` or double-click the title bar |
| Settings | Right-click the board |

## Data

Everything is stored in `%APPDATA%\StickerBoard` (`board.json`, `ink.isf`, `images\`).
Set the `STICKERBOARD_DATA` environment variable to use a different folder — handy for testing or for running a second, separate board.

## Build

Requires the [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) on Windows.

```powershell
dotnet run

# small single-file exe (needs .NET 8 Desktop Runtime)
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish

# standalone single-file exe
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish-standalone
```

The icon is generated by `tools/make-icon.ps1`.

## Translations

UI strings live in [`Strings/`](Strings) as flat JSON files (`en.json` is the reference; missing keys fall back to English).
To add a language, copy `en.json` to `Strings/<code>.json`, translate the values, add the code to `L.Languages` in [`Localization.cs`](Localization.cs), and open a pull request. Fixes to existing translations are very welcome too.
